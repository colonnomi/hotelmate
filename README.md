 # HôtelMate AI

An AI assistant for independent hospitality businesses in France.

## Target customers

- Independent hotels
- Gîtes and guesthouses
- Restaurants and cafés
- Bakeries and pâtisseries
- Bars

## Languages

- French: primary interface
- English: secondary interface

## Initial product modules

1. **AI Guest Reply** — Draft replies to guest enquiries.
2. **AI Review Assistant** — Analyse customer reviews and generate professional reply drafts.
3. **AI Translation & Marketing** — Translate business content and generate social media posts and marketing copy.

## First MVP

The first MVP is the AI Review Assistant. Users manually enter a review and receive a suggested reply in French or English. A human checks the draft before publication.

## Development status

- Implemented: project documentation only
- In development: project setup
- Planned: AI features and integrations

## Future possibilities

- Reservation system integrations
- Order and POS integrations
- Social media campaign assistance
- Paid advertising analysis and assistance

Direct booking, order processing, and advertising account automation are not part of the first MVP.

## Security

Never commit API keys, passwords, tokens, `.env` files, or real customer data.
